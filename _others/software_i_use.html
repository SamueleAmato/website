Software I Use

I prefer software that gets out of the way. My setup focuses on minimalism, speed, and keyboard-driven workflows. Here is a curated list of the programs I use daily.

System & Environment

  • Operating System: Alpine Linux. Extremely lightweight, simple, and secure.
  • Window Manager: dwm. Fast, minimal, and compiles in seconds.
  • Terminal Emulator: Alacritty.
  • Shell: bash.
  • Launcher: dmenu. A ridiculously powerful, yet entirely minimalist launcher by suckless.org.
  • File Manager: ranger. A terminal file manager with vi keybindings. Fast, efficient, and keeps my hands on the keyboard.
  • Password Manager: KeePassXC. Offline, local, and heavily encrypted password management. No relying on third-party cloud servers.

Text Editing & Productivity

  • Text Editor: vim. The standard for fast, keyboard-centric text editing.

NOTE: Lately, I've been experimenting with Emacs. I haven't drawn my final conclusions on it yet, but I am exploring and daily-driving it right now to see how it fits my workflow.

  • PDF Viewer: zathura. Minimal, fast, and vim-like bindings.
  • Presentations: sent. Another beautiful suckless tool that makes presentations directly from plain text files. Occasionally, I also use reveal.js paired with Emacs org-mode.

Internet & Communications

  • Web Browser: Ungoogled Chromium.
  • RSS Reader: newsboat. A terminal-based RSS feed reader. Fast, distraction-free, and keeps me away from the modern web.
  • Chat: Signal is my primary choice. I also use XMPP, and standard email when absolutely necessary.
  • File Synchronization: Syncthing. Decentralized, peer-to-peer file sync. Keeps my devices updated without relying on someone else's cloud.
  • Torrent Client: qBittorrent.

Media & Graphics

  • Video / Audio Player: mpv. Don't bother with anything else.
  • Music Player: mpd (Music Player Daemon) running as a background service. Since I'm currently exploring Emacs, I am using it as my frontend to manage and play my local music library.
  • Image Viewer: sxiv. Simple X Image Viewer. Handles everything I need with vim-like controls.
  • Image Editor: GIMP for heavier editing and modifications.
  • Wallpaper Manager: feh.

Other

  • Cryptocurrency: Monero. True digital cash that is actually private and decentralized.
